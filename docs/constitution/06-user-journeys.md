# 06 — User Journey Map

Page numbers refer to 02/03.

## J1 First run (new actor)
Welcome (2) → Sign In / Create Account (42) → Actor's Baseline (34) → Baseline Task ×4 (35) → Baseline Results (36) → accept pathway (creates enrollments) → Office (1) shows the first real lesson → Lesson (9).
Exit criteria: actor has a primary school and one studied lesson. Skipping Baseline is allowed; Office then offers "Take your baseline" and the Conservatory.

## J2 Daily training loop
Office (1) → Resume → Lesson (9) → Exercise Session (10) (Listening Trap where the exercise uses it) → evidence saved → Workshop (8) shows requirement met → when term evidence complete → Assessment (11) → result → Advancement (12) → Passport (37).

## J3 Scene rehearsal
Office → REHEARSE → Living Scene (14) → Scene Setup (15) choose mode (Unpredictable Director / Partner / Listening Trap) → Live Scene Session (16) → Reflect → Save → take appears in Performance Lab (17) → Take Review (18) (Bullsh*t Detector rubric).

## J4 Note and retake
Director's Chair (41) or a session note → Take Review (18) → "Do the Damn Note" retake → side-by-side compare → note marked applied → evidence + Passport.

## J5 Range drill
Performance Lab (17) → Three Takes Three Tactics: declare 3 verbs → record 3 takes → compare in Take Review (18) → save the strongest as evidence.

## J6 Audition tonight (professional, time-poor)
Office → WORK → Actor at Work (20) → Add audition (21) → Audition Prep (22) → paste sides (26/27) → quick breakdown (24) → Self-Tape Studio (25) → optional Set From Hell pressure run → select take → download.

## J7 Stuck before a take
Office → GET UNSTUCK → Stuck Desk (29) → common issue or Diagnose (30) → Problem Detail (31) → 60-Second Rescue / No Tears Required (32) → Retake Result (33) → save evidence or open a related lesson (9).

## J8 Returning actor
Office shows last real activity and open notes; Baseline can be retaken (new version, history preserved); Passport (37) shows prior record.

## J9 Rehearse with a partner
Rehearsal Lounge (19) → invite link → partner joins → shared Live Session (16), or solo with Unpredictable Partner.

## J10 Account and data
Profile (44) → Settings (45) (language intensity, captions) → Privacy & Data (46) export / delete recordings / delete account → About & Feature Status (47).
